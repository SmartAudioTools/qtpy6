Lance une application qtpy6 (PyQt6) dans le navigateur, telle qu'écrite pour le bureau : un .py, ou un .zip dont le point d'entrée est __main__.py, paquet/__main__.py, le script du nom du paquet, ou le seul .py. Le fichier facultatif lui est passé en argument, comme python script.py fichier.

Par l'adresse : ?script=URL&fichier=URL (adresses encodées ; fichier peut se répéter). Le site qui sert ces fichiers doit autoriser leur lecture depuis une autre page (CORS) : c'est le cas de raw.githubusercontent.com et des gists.

Le script tourne isolé de ce site : il n'a accès ni au stockage ni aux cookies des autres pages, et rien de ce qu'il écrit ne reste d'une visite à l'autre.

Moteur : Pyodide-Qt 0.29.3 (Python 3.13, Qt 6.10.2, PyQt6, GPL v3), servi dans pyodide-qt/.
